接下来：数据如何保存 ↓

本地优先，隐私第一

角色设定、聊天记录和记忆保存在设备上。

  • 数据完全属于你
    可在设备上管理或删除应用数据
  • 自主选择服务
    支持 DeepSeek、OpenAI、本地模型等任意兼容 API
  • 随时备份迁移
    换设备前可导出完整备份，再在新设备上恢复。
  • 开源透明
    代码开放，任何人都可审计隐私实现

你拥有全部数据

调用远程模型、语音或图片服务时，完成请求所需的内容会发送给你配置的服务商。

对话记录 · 角色配置 · 长期记忆 · 日记与日程 · 个人设置
全部存储在你的设备

接下来：安装与配置 ↓

快速开始

系统要求

  • Android 8.0（API 26）或更高
  • 至少 400 MB 可用空间
  • 网络连接（调用 API 服务）
  • 麦克风（语音功能）
  • 相机（视频通话）

1. 安装应用

从 GitHub Releases 获取 APK，安装到你的 Android 设备

2. 配置模型

在设置中添加你的 AI 服务（DeepSeek、OpenAI 等），填写 API Key

3. 创建角色

起个名字、写点人设，选择使用的模型——开始聊天

4. 按需扩展

配置语音、图片服务；安装插件和技能；探索更多可能
